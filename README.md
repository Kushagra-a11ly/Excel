# Excel

A curated Excel repo with templates, dashboards, macros, VBA scripts, and Python automation using openpyxl & pandas. Covers formulas, pivot tables, data analysis, and reporting — built for students, analysts, and developers to streamline workflows and boost spreadsheet productivity.

## 📌 Overview

This repository serves as a one-stop collection of resources for anyone working with Excel — whether you're a student learning the basics, an analyst building reports, or a developer automating spreadsheet workflows.

## ✨ Features

- **Templates & Dashboards** – Ready-to-use Excel templates and interactive dashboards
- **Macros & VBA Scripts** – Automate repetitive tasks directly within Excel
- **Python Automation** – Scripts using `openpyxl` and `pandas` for spreadsheet automation
- **Formulas** – Practical formula examples for common and advanced use cases
- **Pivot Tables** – Techniques for summarizing and analyzing data
- **Data Analysis & Reporting** – Workflows for turning raw data into actionable insights

## 🚀 Getting Started

1. Clone the repository:
```bash
   git clone https://github.com/Kushagra-a11ly/Excel.git
```
2. Browse the folders for templates, scripts, and datasets
3. Open `.xlsx` files in Excel or run the Python scripts with `openpyxl`/`pandas` installed
